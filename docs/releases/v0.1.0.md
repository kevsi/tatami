# Tatami 0.1.0

Première version publiable de **Tatami**, client desktop de lecture de manga pour Windows x64,
écrit pour retrouver sur PC ce que fait **Kotatsu-Redo** sur Android.

## Fonctionnalités

- catalogue de plus de 1 370 sources (moteur `kotatsu-parsers-redo`), filtre par langue,
  recherche globale ;
- fiches de séries : chapitres, dates de publication, filtres et tri ;
- lecteur webtoon virtualisé : saut de page, zoom, raccourcis clavier, reprise exacte de lecture ;
- bibliothèque : favoris, catégories, historique, signets (page précise), mode incognito ;
- téléchargements hors ligne au format `.cbz` : file d'attente, reprise, relecture sans réseau ;
- chapitres récents et notifications par favori (planificateur réglable) ;
- mise à jour du moteur signée (manifeste Ed25519 vérifié, retour arrière automatique) ;
- interface français/anglais, thèmes clair et sombre.

## Installation

- Windows 10 ou 11, x64. Le runtime Java est embarqué : aucune installation de Java n'est requise.
- `Tatami_0.1.0_x64_en-US.msi` (Windows Installer) ou `Tatami_0.1.0_x64-setup.exe` (NSIS).

> **Signature.** Tatami utilise la signature de code gratuite fournie par
> [SignPath Foundation](https://signpath.org/) (candidature en cours, voir
> [`CODE_SIGNING.md`](https://github.com/kevsi/tatami/blob/master/CODE_SIGNING.md)).
> Cette version n'est pas encore signée : SmartScreen peut afficher un avertissement au premier
> lancement — vérifiez l'empreinte SHA-256 ci-dessous avant d'installer.

## English

Tatami 0.1.0 is the first release of a Windows desktop manga reader aiming at feature parity
with Kotatsu-Redo: 1,370+ sources, catalogue search, series pages, a virtualized vertical reader
with saved progress, favourites/categories/history/bookmarks, CBZ offline downloads, scheduled
favourite checks, signed engine updates, and a French/English interface. Requires Windows 10/11
x64 (the Java runtime is bundled). Tatami uses free code signing provided by
[SignPath Foundation](https://signpath.org/) (application pending); this build is not signed yet.
**Verify the SHA-256 sums above before installing.** Code signing policy:
https://github.com/kevsi/tatami/blob/master/CODE_SIGNING.md
